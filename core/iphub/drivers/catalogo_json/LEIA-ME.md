# Embedded declarative catalogue (Catálogo declarativo embarcado)

Every `*.json` in this folder ships in the image and loads at boot as a driver of the
image, section 7. It starts empty on purpose: the three examples of milestone 3 live in
`core/tests/drivers/exemplos/` and prove the engine without offering an invented protocol
as a product. A file lands here through a pull request that names the real device it was
written against.

Todo `*.json` nesta pasta embarca na imagem e carrega no boot como driver da imagem,
seção 7. Ela nasce vazia de propósito: os três exemplos do marco 3 vivem em
`core/tests/drivers/exemplos/` e provam o motor sem oferecer um protocolo inventado como
produto. Um arquivo entra aqui por pull request que nomeia o aparelho real contra o qual foi
escrito.
