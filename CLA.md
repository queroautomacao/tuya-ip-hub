### 7. How to sign

A bot asks for the signature on Your first pull request. To sign, reply on that pull request with exactly this sentence, alone in the comment:

```
I have read the CLA Document and I hereby sign the CLA
```

For each signer, the bot records Your GitHub username, the numeric GitHub account id, the id of the signing comment, the date, the repository id and the pull request number, in the file `signatures/cla-v1.json` on the branch `cla-signatures` of this repository. One signature covers every Contribution You Submit under this version of the Agreement. When the Agreement changes, the bot asks again.

For a legal entity, an authorized representative signs with the same sentence from the GitHub account that Submits the Contributions, names the entity in a separate comment on the same pull request, and every other account contributing on behalf of the entity signs as well.
