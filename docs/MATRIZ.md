# Device matrix (Matriz de aparelhos)

One row per device model and driver. Three states (Três estados):

| State (Estado) | Meaning (Significado) |
|---|---|
| `verificado` | Run against the real device by the person who signs the row, with a GitHub username and a date. (Rodado contra o aparelho real por quem assina a linha, com usuário do GitHub e data.) |
| `simulado` | The driver's tests pass against the simulated device; nobody signed a run on the real one yet. (Os testes do driver passam contra o aparelho simulado; ninguém assinou uma rodada no real ainda.) |
| `declarado` | Support claimed from protocol documentation, with no test yet. (Suporte reivindicado pela documentação do protocolo, ainda sem teste.) |

A state only moves up through a pull request that says what was run, signed by whoever ran it. Rows are sorted by brand, then model. No manufacturer documents and no real network addresses in the notes (use `192.0.2.x`). (Um estado só sobe por pull request que diz o que foi rodado, assinado por quem rodou. Linhas ordenadas por marca e modelo. Sem documento de fabricante nem endereço de rede real nas observações.)
